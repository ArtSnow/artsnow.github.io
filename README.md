# Кто вор? — браузерная логическая игра

Игра работает на HTML, CSS и JavaScript без сборки и сервера. Подходит для GitHub Pages.

## Запуск локально
Откройте проект через локальный HTTP-сервер (например, расширение Live Server в VS Code). Не открывайте `index.html` через `file://`, потому что браузер блокирует `fetch()` JSON-файлов.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите все папки и файлы проекта.
2. Откройте **Settings → Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, сохраните.
5. Через некоторое время игра будет доступна по адресу GitHub Pages.

## Добавление загадки
1. Скопируйте `puzzles/puzzle_001.json`.
2. Измените `id`, `number`, `room`, `furniture`, `characters`, `globalClues`, `solution` и `thief`.
3. Добавьте путь к новому JSON в массив `PUZZLE_FILES` в `js/config-loader.js`.

Координаты начинаются с нуля: `x=0, y=0` — верхняя левая клетка.

### Мебель
Каждый объект в `furniture` содержит:
- `id` — тип предмета (`chair`, `table`, `wardrobe`, `flowerpot`, `tv` и т.д.);
- `x`, `y` — координаты;
- `canPlaceCharacter` — `true` только для мест, на которые разрешено ставить персонажа;
- `image` — необязательный путь к собственной PNG/WebP-текстуре;
- `label` — необязательная подпись.

Клетка с `canPlaceCharacter: true` считается посадочным местом. В первой версии визуально это кресло, но можно завести и другие типы посадочных мест.

### Персонажи
У персонажа есть `id`, `name`, необязательный `image` и массив `clues`.

### Решение
`solution` — объект, где ключом является ID персонажа, а значением — его координаты. `thief` — ID вора.

## Текстуры
Положите свои изображения в `assets/furniture/` или `assets/characters/` и укажите относительный путь в JSON. Если изображение не задано или не загрузилось, используются emoji-заглушки.
